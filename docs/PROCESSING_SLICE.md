# 本地证据与处理链路阶段记录

范围是封版 v1.5 已有 PR 10/11/19/20/22/23/34/35/36 的局部实现，不增加功能或测试编号。该工程切片已可执行，但完整 G0 接口评审、G1/G2 硬件门禁及G3仍未通过。

## 运行本地 API

安装开发依赖（本机已具备）：`python -m pip install -e ".[api,test]"`。

在项目目录启动：

```powershell
$env:SIDECAR_DEV_TOKEN = [guid]::NewGuid().ToString('N')
python -m sidecar.server --synthetic-only
```

仅绑定 `127.0.0.1:8766`，不提供公网绑定选项。另一个终端携带同一进程令牌访问；不要将开发令牌、服务或真实资料对外共享。没有云部署，没有外部模型调用。默认植入两条合成证据，退出后临时数据目录清理，不提供生产密钥持久化。

已实现路由：`GET /capabilities`、`GET /sessions`、`GET /search?q=...`、`GET /reports/{YYYY-MM-DD}?timezone=UTC`、`GET /openapi.json`，以及删除、更正、请求/结束任务、读取产物和取消处理的 POST/GET 接口。请求使用 `Authorization: Bearer <开发令牌>`。服务端凭据映射决定owner，不接收正文中的owner切换；没有CORS开放配置，响应禁止缓存。完整可审查契约见 `contracts/openapi.json`，仍待评审。

## 证据与日报

`sidecar/evidence.py` 从当前合法来源及更正版本构造读取模型。联合关键词可分别来自同窗的屏幕文字和语音文字；候选窗300秒、步长150秒均为实验参数。按owner/会话/boot分组，长未知间隙拆分；折叠重叠窗重复命中。所有命中附来源ID、时间、revision、来源类型和质量提示，时间相邻不推断事实归属。

会议背景与直接命中分栏，人工范围只在范围相交时带出；待归类资料不冒充全场背景。删除讨论范围后，对可能含被删内容的背景关联先隔离；尚未实现人工复核解除隔离，此时继续失败关闭。关键词命中范围资料本身时，创建时刻不标为发言时刻。

日报返回 `coverage_intervals`、`meeting_cards`、`desktop_workflows`。线下单麦转写标识和未知发言人可见；纯手工笔记不算音频覆盖。没有用户计划分母则不计算覆盖率，不推断未记录时段是否在工作；不输出虚构决定、负责人、期限或可信度百分数。报告按IANA日界分段，覆盖夏令时23/25小时；每次读取重新过滤删除/撤销/到期，更正进入输入版本。删除区间元数据独立保留，紧凑回收后仍可显示缺口，不保存被删正文。

这些是合成证据摘录，不是已经完成真实OCR/ASR/语义理解或模型摘要。联合检索目前扫描小规模来源并建候选窗，尚无生产全文索引、中文分词/查询改写评测或性能保证。桌面会话尚无在线会议标记子范围，所以不会将全天桌面记录伪造为会议卡。

## 取消语义

`block_automatic=false` 仅取消当前会话的本轮任务，后续允许新任务；默认取消会持久阻止自动处理。显式 `override=once` 只给该任务例外，不取消长期阻止；`override=allow_automatic` 才重新允许。策略version进入任务幂等键和发布校验，后续取消使在途旧结果不能发布。当前作用域仍是整会话，尚非完整任意时间/阶段范围策略，也无真实供应商计费对账。

## Android 音频下一层接口

`PcmFrameAssembler.java` 实现5–10秒PCM实验帧、连续样本编号、当前源健康标记、暂停代次屏障、尾帧封存及存储失败停止。同步Sink必须在返回前完成受管理持久化或复制，回调返回后可控样本数组清零；不能把对托管内存的清零称为绝对擦除。

`AndroidPcmSource.java` 为尚未开放的G2接口：显式许可、麦克风权限、已确认内置输入、采样率和可见性/存储门禁均满足才允许构造真实采集。读错误、路由改变或系统silenced停止，不切换备用麦克风；停止先阻止后续输入，再封存已接纳样本。时间标记是host_receive及样本编号，**不等于音画校准**。

当前Manifest无RECORD_AUDIO，UI没有录音入口，因此本版本不会启用真实录音。可见性/存储门禁参数还是调用方契约，不是可信设备能力登记；音频加密持久化Sink、FGS与通知急停、硬件源健康、磁盘满和锁屏实际链路仍待集成，未进行实体或模拟器麦克风采集。13项PCM检查只用内存合成样本。
