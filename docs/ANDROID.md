# Android 原生开发记录

基线：已封版 v1.5。选择 PR 36 的既有拒录手工笔记路径推进，不依赖尚未冻结的桌面音频或 UVC 组合；没有新增 PR、状态或 T 编号。阶段仍为局部实现，未通过完整 G0/G1/G2/G3 退出门禁。

## 交付和运行

源码：`android/app/src/main/java/local/sidecar/copilot/`。开发 APK：`android/build/sidecar-dev.apk`。这是本地 debug 签名，不是生产签名或商店发布包。

```powershell
cd android
.\build.ps1
.\build-tests.ps1
```

脚本支持 `-SdkRoot` 和 `-JdkRoot`。本机使用 JDK 17、Android platform 35、Build Tools 35.0.0，直接调用 javac/d8/aapt2/zipalign/apksigner；不下载 Gradle 依赖。仅依赖 Android 平台 API，无第三方运行时库。最低 API 30，target API 35；仅 API 35 模拟器实测，不宣称其他版本兼容。

未自动安装到已连接的实体手机。用户或开发者另行批准设备测试后，才使用明确的目标序列号安装；不要使用不带 `-s` 的 adb 安装/操作命令。

## 已有行为

- 设备认证后进入本地会议列表；新建纯手工笔记会议前确认保存权限和90天开发版保留策略。标题与每条笔记分别从自身创建起算，新增资料不延长旧内容期限；旧版对象保留已有截止，不迁移延寿。
- 笔记明确为 manual_note；可选择会议背景或待归类。结束后可补记，结束时间保持原值；revision 冲突拒绝，不无声覆盖。
- 每场会议独立 Android Keystore AES-256-GCM 密钥，认证有效期300秒，要求设备解锁；AAD绑定会议ID。密钥与加密内容在应用私有空间，未写明文临时文件。
- AtomicFile 写入、fsync 后完成；保存失败不显示成功。整场删除先持久化无正文屏障，再清理密钥和 AtomicFile，重开重试清理。单条删除先保存笔记屏障再重写会议，旧密文被重新放回活动文件时仍先过滤，不返回已删正文；其他笔记保持可读。
- 到期笔记也持久化屏障后清理；标题独立到期后移除原标题；全部资料到期则清理整场。列表遇到某场已到期继续展示其他合法会议。
- 保留时钟保存同开机周期的UTC/elapsedRealtime检查点，以保守上界推进；明显回拨或开机周期变化阻止访问。页面在最早资料截止或最多5分钟后清空，时间设置变化/关屏/离开页面同样隐藏正文。删除开始和读取失败时先移除旧视图，避免已屏蔽内容滞留。
- 禁用备份，内容放在 noBackupFilesDir；窗口 FLAG_SECURE；输入不进入自动填充或 saved instance state，离开页面清空未保存输入并重新要求认证。
- APK 没有 INTERNET、RECORD_AUDIO、CAMERA 或存储权限；没有采集/上传后台服务，也没有麦克风预监听。

## 实际验证

2026-11-10，本地构建和 APK v3 签名校验成功。12项 JVM 原生策略检查通过，映射既有 T34/T35/T38/T42 子集。

使用一次性、只读、无快照的 API 35 模拟器 `emulator-5580`，显式指定已安装 google_apis/x86_64 镜像。旧 AVD 默认路径的 default 镜像缺失，首次启动失败；改用现有镜像后启动成功，未修改原 AVD 配置。临时模拟器内设置测试 PIN，实体设备未变更。

13项 Android 原生存储检查通过：拒绝无同意创建、版本增量、落盘文件不含测试明文、结束后补记保持结束时间与原期限、旧revision拒绝、删除后列表/文件/密钥不可用、剩余会议可读、重开不恢复已删除会议。测试使用合成字符串，未录音、拍照或调用模型。Activity 启动成功，UI层级确认显示开发版、仅本地、麦克风未启用、需认证入口；aapt权限检查仅显示包名，无权限请求。

测试入口：`adb -s emulator-5580 shell am instrument -w local.sidecar.copilot.test/local.sidecar.copilot.StoreInstrumentation`。需已安装两个 APK 且在临时模拟器内完成设备凭据认证。instrumentation APK 不应装到真实数据设备。

## 尚未通过及工程限制

- 未做实体手机、TEE/StrongBox、认证过期/锁屏/重启全面矩阵、恶意备份回滚、SQLite/目录断电恢复及8/12小时测试；不是 Keystore 安全审查通过证明。
- 当前调试版可被具有调试权限的开发工具访问；勿存真实隐私资料。仍为每会议一密钥；单笔记删除采用持久屏障和活动文件重写，不是独立密钥销毁或闪存擦除证明，尚无按时间范围闪回路径。
- 到期访问时清理，尚无后台期限扫描和可信外部UTC锚点。跨设备重启暂保守阻止旧资料，尚无可信重新校时恢复入口；不能把用户改墙钟当作可信证明。新旧资料的独立期限已有实现，但其他来源（照片/音频/模型派生）尚未接入。
- G3规定的完整人工编辑、范围资料、多身份、三段日报、缓冲与远端门禁未接入该客户端；当前没有任何出域通道，界面不能宣称可上传或生成纪要。
- 未保存编辑在离开页面时清空，已明示；认证过期重新认证也会清空未保存输入。需继续完善安全草稿体验后才能用于真实会议。
- createConfirmDeviceCredentialIntent 属已弃用平台入口，目前可在 API 35 编译；后续按官方 BiometricPrompt 路径迁移并验证无设备凭据等负例。
- 状态文本与保存过程目前为主线程小数据原型，尚未做大型会议列表和I/O延迟优化；1 MiB/会议和10000字符/笔记为开发防护，不是已冻结产品限额。

官方参考：[Android Keystore](https://developer.android.com/privacy-and-security/keystore)、[认证与密钥](https://developer.android.com/identity/sign-in/biometric-auth)。只有对应设备的实测报告才能形成支持矩阵。
